# DineSync-Smart-Restaurant-Reservation
A smart restaurant reservation system built using SQL and Node.Js

DineSync is a comprehensive restaurant management system that integrates real-
time reservation tracking with meal pre-ordering. The system features location-based table
pricing (e.g., Balcony vs. Indoor) and allows users to monitor their booking status (Pending,
Confirmed, Denied) while providing management with analytics on customer preferences and
peak hours.
